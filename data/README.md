# 데이터 안내

이 디렉터리는 분석에 필요한 원본 데이터의 로컬 배치 위치입니다. 개인정보와 원문 재배포 조건을 고려해 실제 데이터 파일은 Git에 포함하지 않습니다.

## 필요한 파일

Notebook을 실행하기 전에 Meta Platforms의 2025년 분기별 실적 발표문을 UTF-8 텍스트 파일로 준비합니다.

```text
data/
├── README.md
├── Q1_2025.txt
├── Q2_2025.txt
└── Q3_2025.txt
```

발표문은 [Meta Investor Relations](https://investor.atmeta.com/financials/)에서 해당 분기의 자료를 확인한 뒤 준비할 수 있습니다. 파일명은 위 표기와 정확히 일치해야 합니다.

## 실행 중 생성되는 파일

`yt_comments_ko.csv`는 Notebook의 유튜브 댓글 수집 셀을 실행할 때 이 디렉터리에 생성됩니다. 네 개의 수집 셀이 같은 파일명을 사용하므로 위에서 아래로 실행하면 마지막 영상의 댓글 데이터로 덮어씌워집니다. 이는 원래 분석 흐름을 그대로 유지한 동작입니다.

## 데이터 취급 주의사항

- 유튜브 이용약관과 각 원문의 사용 조건을 확인하세요.
- 댓글 작성자 식별 정보는 외부에 공개하지 마세요.
- 분석 결과를 공유할 때는 수집 시점과 대상 URL을 함께 기록하세요.
- 원본 `.txt`, 생성된 `.csv` 파일은 `.gitignore`에 의해 Git 추적에서 제외됩니다.

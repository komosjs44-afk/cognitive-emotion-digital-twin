# 인지·감성 디지털 트윈

## 프로젝트 소개

한국의 AI 규제 관련 유튜브 댓글과 미국 Meta의 실적 발표문을 비교해 담론의 감성·인지 상태 변화를 분석하고, 마르코프 체인으로 상태 전이를 시뮬레이션한 해커톤 데이터 분석 프로젝트입니다.

## 프로젝트 배경

AI 규제는 같은 기술 이슈라도 사회와 이해관계자에 따라 서로 다른 언어로 논의됩니다. 한국의 대중 담론은 처벌·감시·제도 불신과 같은 반응으로, 미국 기업 담론은 투자·규제 준수·혁신과 같은 전략 언어로 나타날 수 있습니다. 이 프로젝트는 두 담론을 정량적으로 비교하고 시간에 따른 인지 상태의 변화를 디지털 트윈 형태로 표현하고자 시작했습니다.

## 문제 정의

- 한국 대중 담론과 미국 기업 담론에서 강조되는 핵심 키워드는 무엇인가?
- 두 데이터의 감성 분포와 인지 상태는 어떻게 다른가?
- 연속된 인지 상태를 전이 확률로 표현할 수 있는가?
- 특정 프레임의 가중치를 높였을 때 예상 상태 분포는 어떻게 달라지는가?

## 분석 과정

1. `yt-dlp`로 유튜브 댓글을 수집하고 처벌·구속·수사 관련 댓글을 필터링합니다.
2. Meta 실적 발표문에서 안전·무결성·규제·준수·법률·정책 관련 문장을 추출합니다.
3. 국가별 키워드 빈도, 워드클라우드, 분기별 안전·규제 키워드 추이를 시각화합니다.
4. KoNLPy 기반 한국어 키워드 사전과 TextBlob을 이용해 감성 점수를 계산합니다.
5. 부정 댓글의 명사 빈도를 집계해 주요 불만 요인을 확인합니다.
6. 텍스트를 처벌 갈구, 감시 공포, 제도 불신, 투자 의지, 준수 의지, 혁신 강조 등의 인지 상태로 라벨링합니다.
7. 연속 상태로 마르코프 전이행렬을 만들고 한국과 미국의 전이 패턴을 비교합니다.
8. 처벌 프레임 가중치를 조절해 10단계 뒤의 예상 인지 상태 분포를 시뮬레이션합니다.

## 실행 방법

Python 3.10 이상 환경을 권장합니다. KoNLPy의 형태소 분석기를 사용하므로 로컬 환경에는 Java Runtime도 필요합니다.

```bash
git clone https://github.com/komosjs44-afk/cognitive-emotion-digital-twin.git
cd cognitive-emotion-digital-twin
python -m venv .venv
```

가상환경을 활성화한 뒤 의존성을 설치합니다.

```bash
pip install -r requirements.txt
jupyter lab
```

1. Meta 실적 발표문 3개를 `data/`에 배치합니다.
2. 저장소 루트에서 JupyterLab을 실행합니다.
3. `notebooks/cognitive_emotion_digital_twin.ipynb`를 열고 위에서 아래로 실행합니다.

한국어 그래프가 깨지면 실행 환경에 나눔고딕 또는 맑은 고딕 계열 폰트를 설치해야 합니다. 유튜브 댓글은 실행 시점과 플랫폼 정책에 따라 수집 결과가 달라질 수 있습니다.

## 분석 결과

정리 전 Notebook에 저장되어 있던 실행 결과를 기준으로 다음을 확인했습니다.

- 마지막 분석 대상인 YTN 영상에서는 댓글 57개 중 처벌·구속·수사 관련 댓글 15개가 탐지되었습니다.
- 부정 반응 상위 댓글의 명사 빈도에서는 `처벌` 16회, `페이크` 7회, `시청` 6회, `나라` 6회가 나타났습니다.
- 한국 댓글은 처벌 갈구, 감시 공포, 제도 불신, 기타/무관심 상태로 분류되었습니다.
- Meta의 Q1~Q3 발표문은 현재 규칙 기반 라벨링에서 모두 투자 의지 상태로 분류되어 자기 전이 확률이 1.0으로 계산되었습니다.

위 수치는 고정 데이터셋의 벤치마크가 아니라 당시 수집된 댓글과 준비된 발표문을 대상으로 한 해커톤 분석 결과입니다.

## 주요 인사이트

- 한국의 댓글 담론에서는 처벌의 필요성뿐 아니라 시청 행위 처벌, 감시 가능성, 법 적용 기준에 대한 우려가 함께 관찰되었습니다.
- 미국 기업 담론에서는 규제 자체보다 인프라 투자와 규제 준수 의지가 중심 상태로 나타났습니다.
- 동일한 AI 규제 주제라도 대중 반응과 기업 발표는 서로 다른 인지 프레임으로 구조화될 수 있음을 확인했습니다.
- 프레임 가중치 기반 시뮬레이션은 특정 담론이 반복 노출될 때 상태 분포가 어떻게 달라질 수 있는지 탐색하는 도구로 사용할 수 있습니다.

## 한계점

- 유튜브 영상 4개와 Meta 3개 분기 발표문만 사용해 표본의 대표성이 제한적입니다.
- Notebook의 후속 한국 분석은 네 번째 수집 셀이 만든 마지막 유튜브 댓글 데이터프레임을 사용합니다.
- 일부 비교 막대그래프는 실제 집계값이 아닌 해커톤 시연용 입력값을 사용합니다.
- 한국어 감성 분석은 소규모 키워드 사전 기반이므로 문맥, 반어, 부정 표현을 충분히 반영하지 못합니다.
- 미국 데이터는 문서가 3개뿐이고 현재 상태 규칙에서 모두 같은 상태로 분류되어 전이 분석의 해상도가 낮습니다.
- 어떤 상태가 마지막 행에서만 등장해 나가는 전이가 없으면 현재 전이행렬 계산식이 해당 행에 미정 값을 남길 수 있습니다.
- 댓글 수집 결과는 시간, 삭제 여부, YouTube 정책과 `yt-dlp` 동작에 따라 달라질 수 있습니다.
- 마르코프 모델은 직전 상태만 다음 상태에 영향을 준다는 단순화된 가정을 사용합니다.

## 향후 개선 방향

- 분석 대상 영상, 기간, 채널과 기업 문서를 확대해 표본 편향을 줄입니다.
